# Studio 2.1 Resource Model

## Project and Story

The Project is the complete RPG content root. Story is the author's primary
organization and navigation unit, but Actor, Dialogue, and Quest remain
project-level resources with globally unique IDs and one JSON file each.

Every Story has:

- identity, display metadata, tags, and optional entry presentation;
- `owned_resources` and `referenced_resources` lists for Actor, Dialogue, and
  Quest IDs;
- one Flow (`nodes` plus `connections`) as its Runtime logic;
- no manually authored Project Graph edges.

## Ownership operations

`Create` makes a new resource file, assigns its `home_story_id`, and adds it to
that Story's owned membership.

`Create -> Import` reads an existing resource as a template, assigns a new ID,
creates a new file, and records new ownership. Subsequent edits are independent.

`Reference` adds the existing ID to another Story's referenced membership. It
does not copy the file. Every referencing Story therefore observes edits to the
same resource.

Removing a reference only removes membership. Deletion is blocked while any
external Story reference remains. Rename replaces all membership occurrences
atomically.

## Home Story and uncategorized migration

Actor, Dialogue, and Quest schema v2 include `display_name` and
`home_story_id`. A legacy resource without ownership migrates to the generated
`uncategorized` Story. Owned and referenced collections are normalized and
deduplicated with ordinal resource IDs.

Story-to-Story relationships never use membership lists. They exist only as
`EnterStory` nodes in Flow and are visualized by the derived Project Graph.

## Acceptance example

In `DarkGrey 2.1 Acceptance`:

- `royal_mystery` owns `detective`, `final_confrontation`, and `evidence`;
- `kingdom_route` references the same `detective` file;
- `empire_route` owns `empire_detective`, an independent imported resource;
- the two named Dialogue exits lead to separate `EnterStory` nodes.

Real WPF automation edited the Kingdom reference and observed the change from
Royal Mystery, then edited the Empire copy and proved the original unchanged.
Both display names were restored after the check.
