## Verified invariants

- A flow output has at most one target; a flow input accepts multiple sources.
- A logic output accepts multiple consumers; a logic input has at most one source.
- Flow and logic ports cannot be mixed.
- Inputs cannot be connection sources and outputs cannot be targets.
- Port rename/reorder does not break a connection.
- Logic cycles are rejected and flow cycles remain valid.
- Task graphs reject flow ports and flow connections.
- Scope-invalid and compatibility-only node types are rejected where applicable.
- Reconnect excludes exactly one original edge, validates before mutation, and
  preserves the connection's list position.
- Failed connect/reconnect operations do not mutate the document or history.
- Undo/Redo history is isolated from direct edits made to the live document.
- A new successful edit after Undo clears Redo.
- Dynamic-port rename/reorder cannot introduce blank/duplicate labels,
  negative order, or duplicate order within the same role.
- Removing a referenced dynamic port fails closed until the caller explicitly
  confirms removing all incident edges in the same Undo unit.
- The same command bridge and Core transaction path accepts Story, Session, and
  Task scope fixtures; Task Flow rejection remains Core-owned.
- A successful bridge or direct-session host command publishes validation state
  from the command owner that actually ran, so stale preview errors are not
  republished after an unrelated successful edit.
- Property no-ops do not create history; direct live-document mutations cannot
  alias property values held by Undo/Redo snapshots or the WPF projection.
- Unrelated malformed draft nodes/ports do not block a locally valid add, and
  unknown/wrong-scope nodes can be deleted for repair without weakening
  canonical required-node protection.
- Canonical envelope parsing rejects unknown/missing root members, unsupported
  versions/kinds, blank identity, null graphs, legacy roots, and scope mismatch;
  source, editor-owned, and persistence graphs do not alias one another.
