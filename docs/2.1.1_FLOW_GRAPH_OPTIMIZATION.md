# Studio 2.1.1 Flow and Story Graph Optimization

Studio 2.1.1 is a WPF editor usability release. It does not add Runtime node
types or change the Story JSON contract.

## Shared canvas interaction

Story Flow and Project Story Graph now use the same viewport controller:

- left drag moves editable layout nodes;
- middle drag pans;
- the mouse wheel zooms around the cursor;
- toolbar zoom uses the viewport center;
- 100%, fit-all, and reset actions are explicit;
- right click opens a graph-specific context menu and never pans.

The controller clamps zoom to 25%–250% and keeps all fit calculations finite.

## Story Flow

The fixed property sidebar and multiline validation block were removed. Common
resource fields live in each node card, advanced fields are session-only
expanders, ordinary ports are compact circles, and named Dialogue exits retain
their labels. Connections use the real rendered port coordinates and support
press-drag-release creation with a live Bezier draft, valid-target highlight,
blank/self cancellation, and Escape cancellation.

Invalid drafts can move between the five pages of the same Story without an
implicit save. Leaving the Story, project, or application presents
Save/Discard/Cancel. Saving an invalid draft stays in the Story and opens the
unified Problems panel; Discard reloads the disk version.

Flow validation distinguishes project registry membership from Story
membership. A missing project resource is an Error. A project resource not yet
organized into the current Story is a Warning. The grouped selector offers an
explicit “添加为引用” action; opening a legacy Story never writes migration data.

## Project Story Graph

The graph remains derived and logic-read-only. Its permanent diagnostics
sidebar and full-width node buttons were removed. Nodes are denser, edges have
arrowheads and EnterStory source tooltips, diagnostics feed the global Problems
panel, and context menus contain navigation/view commands only.

Cycle handling uses Tarjan strongly connected components. Cyclic components,
including self-loops, produce `project_graph.story.cycle` warnings. The layout
collapses SCCs into a DAG, assigns deterministic layers, and arranges cycle
members in compact vertical clusters. No graph action writes Story JSON; only
`resources/editor/story-graph-layout.json` stores graph layout.

## Verification boundary

Automated tests cover viewport invariants, source-scoped Problems, Flow edit and
membership behavior, invalid-draft navigation, cycle diagnostics, finite layout,
and existing Studio regressions. Real Release WPF acceptance remains a separate
gate and is recorded with screenshots and the packaged executable hash.
