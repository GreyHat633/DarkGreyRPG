# Studio 2.1 UI and Interaction

## Shell

Studio uses the built-in .NET WPF Fluent theme with dynamic system brushes.
The shell has a native menu, vector-icon navigation rail, resizable resource
browser, central workspace, status bar, and resizable/collapsible Bottom Dock.
There are no A/D/Q/S icon placeholders and no decorative New/Open hero buttons;
project creation and opening live in the File menu. The last project, theme,
safe window size, browser width, and Bottom Dock height persist independently
from RPG project data.

## Story-first workflow

The Project home opens on a searchable Story list and the derived Story Graph.
Opening a Story provides five real routes: Overview, Actors, Dialogues, Quests,
and Flow. Create, import-as-new, reference, inspect references, remove reference,
and protected deletion use the same commands and validation as the Core layer.

## Node canvases

Story Flow follows Godot AnimationTree/Visual Shader and Blender node-editor
interaction: nodes are freely draggable, ports are explicitly connected, the
canvas pans and zooms, rectangle and modifier selection are supported, and
copy/paste/delete/undo/redo operate on the graph. Named Dialogue exits become
ports rather than hidden string branches.

The Project Graph is also freely arranged, but its edges are read-only and
derived. Search, filters, auto layout, missing-target/isolated diagnostics, and
direct navigation to a Story's Flow are available.

## Accessibility and responsive behavior

Important editors, lists, graph canvases, ports, resources, and commands have
stable UI Automation names. Node controls expose accessible peers. Hover and
selected states use Fluent dynamic brushes without changing control size.
Text uses wrapping or trimming where appropriate.

Final real WPF automation at a 1700x980 logical window verified critical
controls were visible and inside the window, all five Story routes were
navigable, and the Bottom Dock could resize from 120 to about 220 DIPs, collapse,
expand, and restore after restart. Evidence is in
`.tooling/2.1-acceptance/screenshots/08-...` through `12-...`.
