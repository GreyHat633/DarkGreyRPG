# Studio 2.1 M7 — Project Story Graph

## Boundary

The Project Story Graph is a derived, logic-read-only view. Every valid edge is
recomputed from an `EnterStory` node in Story Flow. Moving a graph node never
changes a Story resource, and the graph has no connection creation or deletion
commands.

Editor layout is stored separately at
`resources/editor/story-graph-layout.json`. The file contains only Story IDs
and finite X/Y positions; it is not consumed by the Java Runtime.

## Interaction

- Free node dragging with immediate independent layout persistence.
- Right-drag pan and wheel/toolbar zoom.
- Search by Story ID or display name.
- Filters for all, connected, isolated, and warning Stories.
- Deterministic layered auto layout.
- `打开 Flow` and node double-click navigate directly to the target Story Flow.
- Missing EnterStory targets and isolated Stories appear in the diagnostics
  sidebar and warning node styling.

## Derivation rules

`EnterStory`, `ENTER_STORY`, and `enter_story` spellings are accepted. Target
properties are read from `story_id`, `target_story_id`, `target`, or `story`.
Only a target matching a project Story creates an edge. A missing or empty
target creates a diagnostic but no phantom node or edge.
