# DarkGrey RPG Studio 2.1.3 Release Notes

## Scope

2.1.3 is a WPF authoring and resource-lifecycle update on top of the 2.1.2
Story Flow baseline. It fixes Project Home selection, consolidates Story
resource libraries, and makes Dialogue/Quest creation a Draft-first workflow.
The Java Runtime remains 0.5.0; Story Flow semantics and the read-only Project
Story Graph boundary are retained.

## User-visible changes

- Project Home selects the first Story when a project contains Stories and
  distinguishes an empty project from a search with no matches.
- Actor, Dialogue, and Quest memberships appear in one compact, scrollable
  library. Resolved references use one shared link icon, missing references a
  warning icon, and source/Home Story information is available in tooltips.
- Story resource library width is resizable, clamped, and persisted. Command
  bars use the available width and remain usable at 1100×700 logical DIPs.
- Create and Duplicate produce unsaved Drafts. The first valid Save writes the
  resource and Owned membership; Discard leaves no resource or membership.
- New Dialogue has an End/`complete` skeleton and a first-line action. New
  Quest has no fake actor and no objectives until the author adds one; ALL,
  ANY, and SEQUENCE completion modes remain explicit.
- Resource-creation failures are surfaced in the running WPF application and
  written to the Studio crash log instead of being treated as silent success.

## Verification and limits

Core tests and WPF contract tests are offline evidence for data and ViewModel
behavior. `studio/qa/2.1.3-resource-creation-ui-acceptance.ps1` is the real
Release WPF/UI Automation check; it uses only a copied project under
`.tooling`, verifies JSON/membership invariants, captures screenshots, removes
only the copied fixture's recovery directory, and preserves atomic per-run
results. Three consecutive accepted runs (including an independent Main run)
passed Release title/process, 1100×700, Project Home selection, unified
libraries, current-host DPI (`GetDpiForWindow=119`), Dialogue/Quest Draft and
first Save, Duplicate independence, Reference/Home Story preservation,
resource-library thumb dragging (`ScrollPattern 0 -> 100`), restart persistence,
process survival, and clean stop. Manual 100%/150% DPI comparison and Minecraft
client observation remain separate gates.
