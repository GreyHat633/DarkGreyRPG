# Studio 便携存储

Studio 以 `DarkGreyRPGStudio.exe` 所在文件夹为根，不依赖启动时的工作目录。
请保留并移动整个程序文件夹，包括随附运行库和媒体工具。

程序根目录只放启动入口 `DarkGreyRPGStudio.exe` 和分类文件夹：

| 目录 | 用途 |
| --- | --- |
| `Program` | Studio 主程序集、托管和原生运行库及语言资源 |
| `Tools/FFmpeg` | 媒体导入和试听工具及其许可 |
| `Docs` | 使用说明、运行库许可和程序文件清单 |
| `Data` | 本副本的全部用户数据；首次启动时创建 |

请从根目录的 EXE 启动。它直接加载 `Program` 内的程序，无需额外启动器进程，不向系统临时目录解压。不要拆开这些分类目录。

| 目录 | 用途 |
| --- | --- |
| `Data/Config` | 本副本的设置、主题和最近项目记录 |
| `Data/Projects` | 本副本管理的项目；项目内包含媒体、引用和恢复文件 |
| `Data/Cache` | 本地缓存 |
| `Data/Logs` | 错误和崩溃日志 |
| `Data/Temp` | 导入暂存和媒体试听临时文件 |
| `Data/Exports` | 故事包默认导出目录 |

新建项目默认在本地 Projects 创建，也可以输入完整项目路径或通过“浏览”选择保存文件夹。自选的外部项目在原位置编辑，其媒体、引用和恢复文件随项目保存；此 Studio 将位置记录在本地设置中，重启或重新打开时不会迁回 Projects。默认位置的项目仍随整个 Studio 文件夹移动；外部项目由用户单独管理。

通过“打开项目”选择尚未在此副本创建的其他外部项目时，先完整复制到本地，再执行格式转换或媒体清理；同名目录使用 `_2`、`_3` 等编号。复制校验失败时保留当前项目和外部原件。包含目录或文件链接的项目会明确报错，避免便携副本仍依赖外部目标。

设置中的内部路径按程序根目录保存为相对路径，自选外部项目路径保持绝对路径。全新副本不读取 Windows 用户设置，也不会自动导入其他副本的项目；首次启动默认深色主题，之后记住用户的主题选择。用户主动选择的外部导出、部署位置仍可使用；Minecraft 运行数据继续归游戏目录管理。

程序目录不可写时显示错误，不向用户目录回退。更新程序使用 `studio/package-studio.ps1`，只更新程序文件并保留整个 Data。成品 ZIP 排除个人 Data，必须携带完整目录发布的托管、原生运行库及媒体工具。

`studio/migrate-portable-data.ps1` 是显式调用的一次性迁入工具，程序启动不会调用它。它将旧设置和日志备份到本地 MigrationBackup，核对项目复制前后的文件数量、大小和 SHA-256，保留原项目目录；清理旧用户目录必须在实际打开验证后另行执行。
