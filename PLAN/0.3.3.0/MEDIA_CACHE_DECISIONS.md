# P6 媒体缓存实施参数

2026-09-13 工程默认值，在实现前记录；不是用户确认项。

- Music：最近 8 个 unique 媒体，正在播放/预加载的另行保护。
- Voice：128 MiB 独立缓存预算。
- Image/Portrait：256 MiB 独立缓存预算。
- 同一媒体用于多个类别时，任一类别保留或当前引用都会保留文件。
- 分块 32768 bytes；沿用现有 DGRS 单条 64 MiB、总解压 256 MiB 上限，不增大包解析上限。
- 客户端请求只允许当前已发送演出引用；32 请求/秒/玩家；迟到帧/连接按既有规则隔离。
- 验证、写盘、解码在后台执行，GPU 上传/释放在客户端线程。
- 临时孤立文件和作者撤销历史需通过安全边界回收，不能在移除引用时删源文件。
