# P8 阻塞标题

工程实现已并入 0.3.3.0-P10 候选包。用户确认的行为是播放结束后继续 Story Flow。

- Story-only title 节点，主标题、副标题、淡入/停留/淡出秒数。
- 独立 TITLE 光标等待；客户端播放完成回执与服务器最短时长、玩家和当前临时 token 一致才推进。
- 同玩家标题 FIFO，上限 16；不会覆盖尚未完成的其他 Story 标题。死亡/断线清理展示，恢复后重播未完成标题。排队与重播是记录在 P8_TITLE_CONTRACT.md 的工程选择。
- TITLE 等待可存档；动画时钟不持久化，不占用 Session 展示状态。
- 网络新增 discriminator 24 CLIENT / 25 SERVER，现有编号保留。
- HUD 支持中文及宽度缩放；Studio 提供专用字段、验证与 Undo。

Title0330Probe 验证透明度曲线、零时长、时间范围、中文包、清除包、回执编码、Story 阻塞/恢复及重复完成拒绝；Title0330InspectorTests 验证所属域、编辑、无效输入和撤销。

实际网络播放时序、并发标题在真实游戏中的显示、不同分辨率及中途死亡/断线画面仍须 P10 实机验证。
