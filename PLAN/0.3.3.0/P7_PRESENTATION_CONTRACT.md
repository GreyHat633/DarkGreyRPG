# P7 实施契约

音乐和画面节点只属于 Session。音乐操作为 play/stop，play 必须引用 OGG；时间单位秒，淡入淡出 0–60 秒。新音乐替换当前音乐，结束清理 DGR 自己的音源。

画面采用完整 layers 数组快照，最多 32 层。每层字段 media_ref、x、y、width、height、anchor_x、anchor_y、z；位置允许 -2–3，尺寸大于 0 且不超过 4，锚点 0–1，z 为 -32768–32767 整数。数组顺序打破相同 z 的平局，不引入用户可见实例身份。上述数量/坐标限额为工程边界，并非用户指定。

服务器持久化当前完整画面、音乐配置及执行序号；重新执行相同音乐节点也产生新序号。当前台词语音只在进入该次台词时播放一次，推进立即停止；恢复快照不会重播（用户确认）。等待条件也要同步展示状态，不能因没有台词而推迟音乐或画面更新。
