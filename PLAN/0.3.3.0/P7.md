# P7 Session 音乐、语音与画面

工程实现已并入 0.3.3.0-P10 候选包。实机播放和视觉验收未完成。

- 音乐 play/stop、循环、淡入淡出、替换交叉淡出；只操作 DGR 自己的流式音源，复用 Minecraft 现有 SoundSystem。
- 台词语音在本次 Line 进入时播放一次；推进立即停止，迟到媒体不会补播已推进的台词。死亡停止音频，复活恢复当前音乐；恢复快照不重播台词，符合用户确认的 Gate E。
- 画面节点声明完整 layers 快照；移除的层自动消失，空数组清除。支持图片导入、层列表、预览、拖动、缩放、排序、坐标/锚点输入及只读对话框/选项参考。参考开关不进入 DGRS。
- 服务器持久化展示状态、音乐序号和台词序号；Condition 等待也投影展示状态。媒体授权扩展到当前音乐和画面引用。
- GUI 后方和无 GUI 的 HUD 绘制均已接入。图片后台解码按活动图片数量调整尺寸，目标总像素上限 16,777,216（约 64 MiB RGBA，另有临时/GPU实现开销）。

验证：SessionPresentation0330Probe 覆盖自动执行、完整快照替换、空清除、NBT、网络往返、迟到语音、推进停止、死亡/恢复、音乐替换淡出及 END 清理。WPF 覆盖音乐配置原子 Undo、布尔配置、画面替换/Undo、非法尺寸拒绝。最终完整检查见 P10.md。

实施边界见 P7_PRESENTATION_CONTRACT.md。不能将探针结果视为真实音响输出、实际拖拽操作或视觉验收。
