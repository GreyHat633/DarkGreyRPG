# 标题实施契约

用户确认：标题播放结束后才继续 Story Flow。

标题拥有独立 TITLE 等待边界；属性 main、subtitle、fade_in、stay、fade_out，时间单位秒。主标题非空，副标题允许空，各时间 0–60 秒。文字各最多 1024 字符。工程选择：同一玩家来自不同 Story 的并发标题排队，最多 16 项，不覆盖尚未播完的标题。死亡或断线清除显示，复活或重连重新播放当前标题；未播完不推进流程。

客户端完成回执携带服务器临时 token，服务器验证当前玩家、当前排队项和最短播放时长后才推进。重复或陈旧回执不推进。动画计时不进入长期存档，TITLE 光标持久化；重新进入后从该标题重新播放。现有 Session 不持有标题。
