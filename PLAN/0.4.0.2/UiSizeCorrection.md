# 0.4.0.2 Runtime UI 尺寸自查与修复

当前修正版已重新发布，见 [Rerelease.md](Rerelease.md)。以下保留此前阶段的来源、哈希与当时状态。

2026-10-10。对应用户要求：“那其他的 ui 呢？有没有大小窗口被你波及到？自查并修复”。

本页记录 `00D03FC1…` 尺寸恢复检查点；后续分数缩放笔画粗细修正和当前本地产物见 [FontCoverageCorrection.md](FontCoverageCorrection.md)。本页原始哈希及证据保留为对照。

结论：先前字体修复确实越过了绘字范围。通知取消整体自适应缩放，其他若干位置把原字号提高到像素倍率档位，造成面板或内容变大。本次对照 `v0.4.0.1` 恢复这些尺寸与布局规则，保留单次无阴影绘字、去除强制合成粗体、最近邻采样、像素定位及 GL 状态恢复。Studio 未修改。

## 已恢复的显示规则

| 位置 | 原发布版的问题 | 本次修复 |
| --- | --- | --- |
| 任务通知卡 | 移除按窗口高度缩小的规则；标题、小字和行高改变；短窗口减少可见卡 | 恢复三卡预留尺度 `max(.25,min(1,(scaledHeight-24)/300))`、标题 1.25、小字 .85、标题行高 13、最多三卡及第四卡 FIFO 等待。保留绘制前先准入再测量的空布局修复 |
| 任务追踪 HUD | 用户字号被提高到 `DialogueFontDrawing.scale()` 的档位 | 布局和绘字恢复 `PlayerUiPreferences.textScale()` |
| 任务窗口列表 | 字号及列表行高随提高后的档位变大 | 恢复原用户字号和行高公式 |
| 对话选项按钮 | 字号提高后增加换行、按钮高度和翻页占用 | 恢复原用户字号，沿用同一个测量矩形绘制与点击 |
| Title 主副标题 | 强制最小字号、多行换行、动态副标题位置 | 恢复单行按屏宽适配，主标题 3、副标题 1.5，副标题固定偏移 35 |
| 故事图谱节点标签 | 缩放向上取档，较小节点隐藏文字 | 恢复随连续 zoom 缩放及原 117 单位裁切宽度，不新增隐藏条件 |
| 原 GuiScreen 悬停提示 | 改用了目录提示框的额外 240 宽度换行、位置、间距和背景 | 恢复本地 Minecraft 1.7.10 GuiScreen 的提示框边界、渐变、首行与后续行间距，只替换字体绘制。原目录提示框不变 |

| 设置、任务、玩家状态检查、故事包窗口 | 外框、最小尺寸、移动缩放、按钮矩形未改；四个实际生产窗口的发布版与修正版外框已实机逐项比较 |

| 物品指名器、目录搜索、绑定确认框 | 背包格、目录区域、输入框参数和弹窗矩形未改；保留输入编辑行为与单次绘字 |
| 故事选择、任务提交选择、候选物品窗口和浮层 | 行间距、面板/按钮/物品格边界未改；使用公共提示框的位置已随上面的修复恢复 |

前景窗口和通知继续使用不透明背景，防止下层 HUD 的字透出；这是保留的重影修复。去除合成粗体会改变实际字宽，可能影响自然换行，但不新增窗口尺寸或字号档位。

## 验证

- Runtime build 与 42 项版本 Probe 全部通过；额外 `utilityWindow0324Probe` 通过。最终测试驱动修正后再次 build，并重跑字体策略、通知和工具窗口 Probe，通过。
- 698 个产品类只保留一个受控底层绘字入口；提示框原边界、通知尺寸阈值、三卡 FIFO，以及 HUD/列表/选项不提高字号均有回归约束。
- 19 组隔离 Forge 实机记录，修正版覆盖 GUI 倍率 1、2、3、4。生产窗口比较如下，单位为 GUI 坐标；相同物理画面为 882×640、倍率 2。

| 窗口 | 发布版与修正版均为 x / y / 宽 / 高 |
| --- | --- |
| 设置 | 31 / 0 / 380 / 320 |
| 任务 | 0 / 10 / 441 / 300 |
| 玩家状态检查 | 0 / 0 / 441 / 320 |
| 故事包管理 | 45 / 32 / 352 / 256 |

GUI 倍率 4、物理画面 1902×984 时，通知外宽约 760→562 像素，实际截图可采样的深色内部宽度为 752→557 像素。125% 字号选项在倍率 2 下恢复 200%→125%，测试文本的按钮高度 138→60；倍率 4 下恢复 150%→125%，高度 82→60。保留最近邻采样与状态恢复，实机诊断均为 true。

实机验证覆盖通知/追踪、真实选项按钮和提示框、上述四个窗口。故事包使用空展示快照核对窗口边界，没有将其写成“已验证所有图谱节点”。Title 和图谱标签的规则通过源码对照检查。测试快照只用于本地展示，不是业务验收。两客户端已从原生菜单退出，隔离服务器正常保存并停止；无关进程未操作。

额外旧 `dialogue0333Probe` 失败，原样保留：它假设 320×240、字号 1.5，而现有容量 profile 已按 640×360、有效字号 2.0 校准。探针、布局、profile 和生成器与 0.4.0.1 都相同；没有改生产布局迁就旧断言。原人工听音、用户延后项等既有记录保持原状态。
