# DarkGrey_RPG 0.3.0.0 / 0.3.1.0 成品对照验收清单

> 用途：0.3.1.0 开发完成后，按本文件逐项对照成品，检查 0.3.0.0 应有的“编制框架”是否真正落地，以及 0.3.1.0 应有的“Minecraft 游戏内对接”是否完整实现。
>
> 建议填写方式：每项在“结果”处填写 `通过 / 部分通过 / 未实现 / 被0310替代 / 不适用`，并在备注中记录截图、复现步骤或问题。
>
> 重要：如果 0.3.1.0 已明确替代 0.3.0.0 的旧语义，最终成品以 0.3.1.0 为准。

---

# 1. 版本边界

## 0.3.0.0

定位：**RPG 编制框架里程碑**

核心目标：

> 把 Studio 的主工作流、资源树、Story / Session / Task 三层 Graph、●流程接口、◆逻辑接口和 Runtime 执行闭环做成真正可实操的 RPG 编制框架。

一句话：

> **0.3.0.0 解决“RPG 怎么编、Graph 怎么表达、Runtime 怎么跑”。**

## 0.3.1.0

定位：**Minecraft 游戏内落地版本**

核心目标：

> 在 0.3.0.0 的基础上补齐故事包、服务器、实体/物品身份、游戏内工具、跨故事逻辑接口、玩家独立进度和实际 Minecraft 表现。

一句话：

> **0.3.1.0 解决“编好的故事怎么真正进入 Minecraft 并被玩家游玩”。**

# 16. 0.3.1.0 —— 收纳箱

## 生存模式

- 空箱右键生物：捕获实体本体。
- 实体从世界移除。
- 若有 NPC ID，该 ID 继续被占用。
- 已收纳箱右键方块：释放原实体。
- 释放后箱子变空。

## 创造模式

- 空箱右键生物：原实体不移除，只保存模板。
- 已收纳箱右键方块：可无限生成副本。
- Group ID 继承。
- NPC ID 不复制。
- 箱子继续保持“已收纳”。

## 图标

- 空置：开盖木箱
- 已收纳：闭盖木箱

# 23. 0.3.1.0 —— 【条件】最终规则

正式节点：

> **【条件】**

输入：

- ● 流程
- ◆ 逻辑

输出：

- ● 是
- ● 否

运行：

1. ● 到达立即读取 ◆。
2. 对应出口已连接 → 立即离开。
3. 对应出口未连接 → 停在此处等待。
4. ◆ 状态变化后重新检查。
5. 一旦已有连接的出口可走 → 发一次 ● 并结束等待。
6. 离开后停止监听。

因此：

- 是/否都接：即时判断
- 只接是：等待 true
- 只接否：等待 false

# 31. 优先检查的 15 项

如果验收时间有限，先看：

1. 左资源树 / 中 Graph / 右 Inspector 是否完整。
2. 会话是否真正局部 Graph。
3. 任务是否真正局部逻辑 Graph。
4. 会话/任务是否可拖入 Story Flow 成为聚合节点。
5. ●/◆ 是否真正有不同连接语义，不只是视觉区别。
6. 动态端口改名/排序是否不断线。
7. 0310 Task 是否删除【激活】。
8. 【目标】生效条件是否只暂停统计、不清空进度。
9. 【结算】是否固定唯一且只输出一个结果。
10. Story Graph 是否只开放 ◆跨故事接线。
11. 【开始】是否实现“多个启动方式 + 独立●输出 + 可接◆”。
12. 【条件】是否符合即时判断/单边等待统一语义。
13. NPC ID 是否真正外置，CNPC 复制不复制唯一身份。
14. 玩家 A/B Story/Task 是否真正隔离。
15. 故事包是否支持 `/dgr reload` 热加载且不清进度。
