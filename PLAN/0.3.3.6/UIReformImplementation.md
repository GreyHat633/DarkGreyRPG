# Studio 界面整改与三层公开端口改革

> 后续修正：Project 连线编辑已恢复，公开输出上下按钮已移除，左栏拖动反馈已改进。最新交付和验收见 [UIFollowupAcceptance.md](UIFollowupAcceptance.md)；本页保留此前记录。

本记录对应本轮用户确认的整改计划，覆盖原 15 项反馈。版本继续使用 0.3.3.6；不生成成品 ZIP，不创建 Release、标签或远端提交。最终测试与交付状态见 `UIReformAcceptance.md`。

## 界面

- 新建故事不再提供 UID 字段；资源名称为空，以焦点相关的占位文字引导，空白名称不能提交。故事列表使用辅助字号的 `UID: `，去掉“新格式”和内部资源栏重复 UID。
- 角色、角色组、物品、物品组采用用途说明，资源列表统一六类方括号标签。点击资源栏或画布空白清除资源选择；资源 Inspector 内操作不提前清除选择。
- 剪刀按钮保持持续模式；普通模式 Ctrl 按住临时启用，持续模式按 Ctrl 关闭且本次按住期间不重新启用。文本编辑快捷键、失焦与视图切换独立处理。项目图没有剪刀和普通组合入口，也不允许改动连线结构。
- 终止、结束、结算归“流程”，标题归“演出”。台词改为预计行数、页数；估算采用 1280×720、GUI 缩放 2、默认对话设置的固定基准与运行端字宽规则，动态文字明确为估算。长文本不再因推荐容量被拒绝。

## 公开输出与结算

- 所有公开输出边界必须保存 `port_id`、`display_name`、`display_order`。Flow 与 Logic 各自排序；新边界追加，缺失或重复排序报错，不使用位置或数组顺序修补。
- Session/Task 聚合节点与 Inspector 共用输出编辑组件，独立折叠 Flow/Logic 卡片，支持改名、拖动与上下排序。空类别隐藏；引用资源不提供修改入口。项目图的 Story Inspector 只允许排序。
- 修改定义进入统一撤销栈，投影更新使用稳定端口 ID。展示更新同步到历史快照，避免保存产生额外的“投影变化”撤销步骤；跨视图撤销采用工作区自己的历史序列。
- Task 改为多个独立结算节点，每个一个 Logic 条件输入和一个外部 Flow 结果。按最新规则，结算与目标都可删至零个，新 Task 默认只有一个目标。旧多结果槽模型及编辑器已移除；当前交付与验收见 [TaskUIFixAcceptance.md](TaskUIFixAcceptance.md)。
- Runtime 在逻辑求值稳定后收集条件，按显式 Flow 顺序决定唯一结算结果。最终状态与奖励收据保持一次性；Logic 输出排序不进入优先级。Story/Session 展示顺序不改变成员执行指纹，Task Flow 顺序进入指纹。
- 读取、保存、复制、导入导出和模板均使用新合同。启动恢复先只读校验全部当前图资源，拒绝旧合同并显示具体错误；不崩溃、不自动改写旧项目，也不替换已打开的正常项目。

## 故事组

- 组成员仅由 Flow/Logic 连通关系派生。左侧卡片包裹标题与成员，普通文字标题通过右键重命名；组和独立故事都能调整顶层顺序并持久化。
- 项目图的故事组框支持选择、框内空白拖动、整组位移、颜色、折叠和删除。成员仍能单独移动；布局、组名、颜色和导航顺序均为编辑器元数据。
- 删除计划展开完整来源容器，检查组外资源及连线依赖，列出受影响项目文件后统一提交。本地故事删除，引用包从当前项目解除，外部原始包保持不变；事务支持失败回滚和撤销。
- 修正了外部 Story 参加连通分量时的节点集合，以及组删除恢复后键盘焦点丢失造成的连续 Ctrl+Z/Ctrl+Y 失效。
