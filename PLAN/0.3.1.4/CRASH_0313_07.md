- 最后一个已确认 GraphRevision：`0`
- 目标点击没有形成一个可确认完成的 canonical revision；进程在 selection projection 重入中死亡。

## 根因结论

根因是 **UI projection 被错误地重新解释为用户输入**：

1. `SelectedObjectiveActor` 的 TwoWay setter 执行 canonical mutation；
2. setter 随即无条件 `RefreshFromHost()`；
3. refresh 创建全新的 option list / option instances，并通知 ItemsSource 与 SelectedItem；
4. WPF 在正在处理 ComboBox mouse-up / selection commit 时再次回写 setter；
5. 现有 `_suppressTargetedRefresh` 只抑制部分 host notification，不能阻止 projection-driven setter re-entry；
6. 循环最终耗尽 UI thread stack。

这同时解释“目标切换极慢”和“闪退”，并满足 PLAN 对真实 crash stack 后才能宣布根因的要求。
