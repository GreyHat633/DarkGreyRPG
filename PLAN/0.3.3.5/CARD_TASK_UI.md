# Studio 卡片交互与任务界面修正 — 0.3.3.5

已构建并替换正式自包含 Windows x64 Release EXE 和配套 JAR。没有新增存档字段或网络协议；没有 GitHub 发布。USER_ACCEPTED=NO。

## 实现

- 图片属性内恢复两张完整分区卡片；标题占满一行，动画步骤各自可折叠，标题左侧可拖动。
- 背景、内边距、标题和字段都参与动画选择；窗口外部点击取消。工具栏保持选择；处理 ComboBox 鼠标捕获，点击弹窗外部后再次清除恢复焦点带来的误选。
- 会话状态按图片及动画标识共享给节点和 Inspector，动画增删、排序与撤销回放保留折叠状态。选择选项的拖动手柄移到标题左侧。
- 故事折叠清空详情时同时使缓存键、滚动范围和历史详情标识失效；重新选择重建目标内容与点击区域。
- 候选网格去除标题占位及 250 ms 开启等待；分页页脚仅多页出现，沿用缓存、200 ms 离开关闭和 1.5 秒轮播。
- 故事使用正常字重及主题强调色。HUD 按故事分组、每任务一个目标、名称省略和完整任务块截断，图标数量同行，限制宽度和总高度。

## 验证结果

- WPF 定向回归 94 通过、0 失败。Java build、Checkstyle、construction0335Probe 通过。日志见 evidence/card-ui。
- 最新正式 EXE 实际鼠标验证：卡片内边距选中、外部取消、打开下拉后外部取消、统一减号删除、Ctrl+Z 恢复、折叠动画拖动排序及撤销；有对应 card2-* 截图。选择节点标题左侧手柄在截图可见。
- 游戏“已完成”和“进行中”分别连续十次收起故事、再展开、选择相同任务；详情文本区域十次 SHA-256 一致，首末截图均保留。早期点击未等待游戏更新鼠标位置的试跑不计入结果，最终脚本加入移动后等待。
- 候选网格与标准 tooltip 在首次 50 ms 截图采样帧已同时显示（PNG 编码完成约 106 ms）；热缓存同样在首帧显示。此候选组可能被轮播预取，不能将此结果标为严格冷缓存。45 候选网格翻页与离开关闭进行了鼠标操作。
- 实际检查深色 100% 和浅色 150% 文字，中文故事名称清晰；三任务追踪时完整块截断、显示“另有 2 项”，前景任务面板遮罩下 HUD 保留。截图 card-white150-task、card-three-hud。

## 尚未形成完整实机证据的矩阵

严格冷缓存网络延迟、全部缓存上限压力、跨页历史目标十次循环、多故事/同名故事组合、所有 GUI 缩放与窄屏组合，以及节点侧全部操作与 Inspector 的逐项对照，未在本轮完整跑齐。不能将定向通过解释为这些矩阵已验收。折叠高度曲线沿用已有组件及回归，本轮没有重新采样全部节点高度。
