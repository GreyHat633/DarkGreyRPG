# 项目级保存与游戏窗口底色统一

## 行为修复

- 任务、设置、实体指名器、物品指名器、复制器共用任务窗口外层底色 `0xEE161616`；任务内容区颜色提取为 `WINDOW_CONTENT`，设置内容区使用同一颜色。
- 普通“保存”和 Ctrl+S 调用项目级保存，与“保存全部”一致，覆盖当前故事及后台保留故事的 Story、Session、Task 图与布局，再保存项目中已打开的角色等资源。
- 故事存在未保存图时可以切换故事，草稿保留在内存中；返回时恢复原编辑实例。切换至无效故事、旧格式故事或项目图谱也不清除这些后台草稿。
- 删除故事不要求先保存；正常删除确认仍保留。删除成功后清理该故事的活动/后台草稿及所属角色缓存，其他故事的未保存编辑保留。取消删除不改变草稿与磁盘数据。
- 旧格式会话/任务草稿保存后继续保留选中状态。项目级保存会一起写入由会话/任务出入口变更引起的故事聚合节点同步。

## 原因

已有后台草稿保留与保存全部实现，但切换入口还残留“未保存禁止离开”的检查，普通保存仍绑定当前资源保存。删除还会拒绝未保存故事与角色。界面外层背景分别使用了硬编码灰色与不同常量；设置缺少任务窗口所用的内容层背景。
