# DarkGreyRPG 0.3.3.1 更新总览

日期：2026-09-16

分支：`codex/0.3.3.1`

基线：`codex/0.3.3.0`
状态：工程实现与本文所列验证已完成；`USER_ACCEPTED=NO`；本次发布为 GitHub 分支快照，不是 GitHub Release。

## 1. 版本目标

0.3.3.1 集中完善 Studio 的节点编辑体验、会话演出、任务反馈、媒体资源生命周期和 Minecraft 运行目录。版本继续使用既有 Canonical Story、Session、Task 运行时，没有引入第二套 Runtime，也没有改变资源身份语义。

本版本的主要结果是：

- Studio 节点可以直接、稳定地编辑，界面层级、菜单、Inspector 和画布布局更紧凑。
- 台词、头像、语音、音乐和完整画面形成可编辑、可预览、可导出的演出链路。
- 游戏端支持逐字台词、全局速度设置、可选单句覆盖、非阻塞语音及标题流程控制。
- 任务接取、目标变化和任务终态在右上角以结构化卡片提示。
- 故事包媒体在 Story 启动后按关联关系预加载，并以固定并发和包级 LRU 管理。
- Minecraft 文件统一进入 `DarkGreyRPG` 目录；StoryPackages 只保存用户故事包。

## 2. Studio 编辑体验

### 2.1 节点、字段和 Inspector

- 节点名称统一为 `类型「名称」`，Inspector 删除重复的节点类型小标题。
- 节点帮助、输入提示、正文和错误提示使用不同字号与灰度；空校验信息折叠，不再占据空白行。
- Inspector 的左侧拖动条实际改变画布可用区域，画布内部视口随宽度变化重新布局。
- 节点属性编辑器修复下拉集合抖动、控件命中与节点拖动冲突、撤销后端口几何未刷新的问题。
- 数值输入支持水平拖动实时更新预览；显示值压缩到易读精度，直接输入仍可保留高精度。
- 画面图层的位置使用左上角坐标语义，删除与位置重复的锚点输入；拖动提供边界、中心和相邻元素吸附。
- 图层名称、图层顺序、位置和尺寸集中在可折叠的“图片属性”卡片中，默认收起。

### 2.2 右键菜单与图谱

- 添加菜单新增“演出”分组，音乐和画面移入该组；原有图类型限制保持不变。
- 项目故事图谱删除跨 Story 下拉选择方式，Story 之间通过用户手动连接 Flow 或 Logic 端口。
- 项目图谱空白处的右键添加只创建 Story；故事内图谱使用“添加”。
- 右键菜单统一为“复制”和“粘贴”，二级菜单分别包含“节点”和“参数”。
- `Ctrl+C`、`Ctrl+V` 支持多选节点复制；文本框获得焦点时仍执行普通文本复制粘贴。

### 2.3 节点复制与参数复制

- 节点复制保存配置、相对位置、选中范围内连线和动态端口身份；范围外连线不复制。
- 会话和任务节点复制时深复制对应资源及内部图，ID 使用 `_copy`、`_copy1`、`_copy2` 递增。
- 同一次复制中多处引用同一资源时只生成一份新资源；固定唯一节点出现在复制集合中时拒绝整次粘贴。
- 参数复制使用独立剪贴板，保留目标节点身份和位置；不同节点类型、不同图类型不能粘贴。
- 会话和任务参数粘贴替换内部图，但保留目标资源 ID、显示名称、标签和任务说明。
- 动态端口只按稳定身份或唯一的名称、类型、方向匹配；共享引用和失配连线使用确认流程。
- 一次粘贴中的节点、资源、文件和连线变化组成单个撤销/重做操作。

## 3. 角色头像与表情差分

- “头像差分”改名为“表情差分”，“导入差分”改名为“导入”。
- 导入时默认使用文件名，不再要求先输入名称；重名自动追加 `(1)`、`(2)`、`(3)`。
- 支持右键重命名和 `F2` 快捷键。
- 台词节点中的“头像差分”改为“头像”，并显示当前选择的预览图。
- 角色资源保存后，已打开的会话节点立即刷新可选头像，无需重启 Studio。
- 游戏端头像与对话框共同提交显示；进入选项时保留上一句完整台词和头像。

## 4. 台词、语音与音乐

### 4.1 Studio UI

- 台词节点按“角色 → 头像 → 预览 → 台词文本 → 显示速度 → 语音/音效”排列。
- “本句语音”改为“语音/音效”；导入和移除左右对称，播放器为 `-5s / 播放 / +5s`、进度条和音量。
- 语音/音效使用复选框控制；默认关闭，勾选后展开配置卡片。
- 音乐节点使用同一播放器卡片，按钮为“导入”和“停止”，删除多余说明文字，并支持音量、循环、淡入和淡出。

### 4.2 游戏行为

- 台词按经过时间逐字显示，正确处理中文、换行和 Unicode；0 字/秒表示立即完整显示。
- 未显示完时点击只补全当前句，再次点击才继续，不重复播放语音。
- 进入下一句时停止上一句语音；语音和音效不阻塞故事流程。
- 台词节点默认跟随玩家全局速度；勾选“自定义显示速度”后才使用节点的 0–120 字/秒值。
- 游戏中按 `P` 打开非暂停设置窗口，目前提供台词显示速度；窗口支持拖动、四角六点缩放和持久化。
- 设置保存到 `DarkGreyRPG/Config/darkgrey-rpg-windows.properties`。

## 5. 标题与流程时机

- 标题节点提供“播放完再继续流程”。旧节点和缺字段的旧故事包默认开启。
- 开启时标题播放完成后推进；关闭时标题成功提交后立即推进，后续任务可以在标题仍播放时激活。
- 后台标题回执只清理演出，不会再次推进已经继续的 Story。

## 6. 画面节点与图片编辑

- 画面节点表示进入该节点时的完整画面状态；A → B 整体切换为 B，B 为空时清除画面，不继承 A 的图层。
- “添加图片/移除图片”缩短为“添加/移除”；上移、下移使用实心三角按钮。
- 新图片保持原始像素宽高比，居中适配到 16:9 预览区域的 75% 范围，已有图片尺寸不改写。
- 支持边缘和四角八个缩放手柄；图层列表顺序与 Z 顺序同步并可撤销。
- 图像异步导入在完成时检查项目、节点和加载状态，切换节点或项目不会写错对象。
- 格式不符、损坏、读取失败和像素超限时保留原配置、恢复按钮并给出简洁错误信息。
- 修复两个串联画面节点分别导图导致异常逃逸和 Studio 崩溃的问题。
- 修复离开会话再返回时画面缩略图成为黑块的问题。

## 7. 多格式图片导入

- 角色默认头像、表情差分和画面图层统一支持 PNG/APNG、JPG/JPEG、WebP、BMP、GIF、TIF/TIFF。
- 根据文件内容识别实际格式，不依赖扩展名。
- 导入后转换为静态 RGBA PNG；动画和多页图片取第一帧，透明通道保留，源文件不修改。
- 继续执行文件大小、像素上限、完整解码、原子安装和临时目录清理检查。

## 8. 任务提示

- 服务端依据真实任务状态产生稳定的任务实例、目标和事件标识；初始同步、重连和普通计数变化不产生提示。
- 同一任务的完成旧目标和激活新目标按结构合并，与事件到达顺序无关。
- 文案层级为：辅助事件类型、放大加粗的任务名称、已完成目标、新目标；任务终态清除过时目标。
- 当前展示文案为“任务接受”“任务更新”“新目标”“已完成”“任务完成”“任务失败”。
- 卡片采用灰黑背景和灰色细边框；最大宽度 190，按实际文字行数计算高度，不保留空白占位。
- 动画为向左滑入 0.6 秒、完整显示 4 秒、向右滑出 0.6 秒，使用平滑加减速和单调时间。
- 更新可刷新阅读时间而不重播入场；退出期间更新从当前位置平滑返回。
- 最多同时显示三张，后续任务等待最早卡片完全退出；其余卡片平滑补位。

## 9. 故事包媒体生命周期

- 一个 Story 的开始节点触发时，预加载该 Story 使用的图像和音频。
- 通过项目图谱 Flow 连接或 Logic 输入/输出连接的 Story 都算关联 Story，同样进入预加载计划。
- 最多并发预加载 3 个故事包；缓存以完整故事包为单位，不产生半包可用状态。
- 运行时最多保留 10 个故事包的媒体缓存，超出后按最旧使用时间逐包淘汰。
- 头像、画面和音频读取优先使用已经就绪的本地缓存；首句在首次触发前没有预热机会时仍可能受实际磁盘/解码延迟影响。
- 这些规则没有提供玩家配置入口，也没有按附近 NPC 推断触发动机。

## 10. 运行目录与仓库迁移

开发仓库迁移到：

`E:/Java/MinecraftMod/DarkGreyRPG`

Minecraft 内的运行数据统一到：

```text
<Minecraft>/DarkGreyRPG/
├─ Project/
├─ StoryPackages/
├─ Cache/
│  └─ StoryPackagesRuntime/<安装目录哈希>/
├─ Config/
└─ Exports/
```

- `StoryPackages` 只保存用户放入的 `.dgrs` 文件，不再生成 `.dgrs-runtime`。
- 程序生成的 Story 包运行数据位于 `Cache/StoryPackagesRuntime`，按安装目录隔离。
- 启动时迁移可识别的旧默认目录；冲突不覆盖，无法确认归属的内容不递归删除。
- 显式配置的外部项目和故事包路径继续保留。
- README、QA 脚本和 IDEA/Gradle 工作目录更新为无下划线的新仓库路径。

## 11. 其他 Studio 修复

- 资源选择器可拖放，默认选择和高级选项在节点内与 Inspector 同步。
- 奖励节点支持从右键菜单创建未选择的草稿，并恢复正常奖励布局和主题颜色。
- Start 参数按卡片组织；旧故事端口在读取和导出时补齐稳定身份，保留源文件不被读取过程改写。
- 返回项目首页后，故事端口和连线立即刷新；新增、切换或删除已连接端口时同步保存和清理连线。
- 画布视口在 Inspector 改宽时保持中心内容，节点实际可用空间随布局变化。
- 音频预览修复 TimeSpan 格式异常；正式构建保留本地媒体工具。

## 12. 兼容性与数据接口

- 标题字段 `wait_for_completion` 缺失时解释为等待播放结束。
- 台词 `custom_text_speed` 缺失时为 `false`；`text_speed` 缺失时默认草稿值 30。
- 网络中的台词速度 `-1` 表示跟随客户端全局设置，自定义值保持 0–120。
- 旧 Story 终止端口在脱离磁盘的快照中补齐稳定身份；显式身份保持不变。
- 媒体缓存、流程/逻辑关联预加载和目录迁移不修改已持久化的资源 ID、mod ID 或世界 SavedData。

## 14. 已知验证边界

- `USER_ACCEPTED=NO`：代理验证和分支推送不等于用户个人验收。
- 没有宣称全部功能、所有 DPI、所有 GUI 缩放或全部故事包排列组合无缺陷。
- 多玩家、大型媒体包、磁盘满、真实断流和长时间服务器压力没有形成完整基准。
- 任务提示完整动画录像曾被自动审批拒绝；自动时间检查和静态实机截图均保留，但不把截图表述为录像验收。
- 最终任务提示文案、位置和标题放大后的构建已通过；本次汇总前没有为这三项排版微调重新进行 Minecraft 截图。
