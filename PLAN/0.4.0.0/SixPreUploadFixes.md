# 0.4.0.0 上传前六项修正

日期：2026-10-08。按用户最终方案实施，版本仍为 0.4.0.0。

## 实现结果

1. 删除 Choice 选择提示的节点编辑、Inspector、动态文本入口、搜索和帮助。旧 `prompt` 兼容读取后忽略；打开不自动回写，本地正常保存和导出移除该字段，引用包原字节保留。Runtime 移除提示参数和访问接口，Choice 帧文本固定为空，网络帧字段结构不变。选项正文、条件、不可选原因及端口身份保持。
2. 问题面板提供“清空问题”，清除当前显示项和红色计数，空列表禁用。输出和日志保留，后续错误、验证可重新报告。
3. 添加菜单中“流程”固定最后，其内部终止／结束／结算固定最后，其他类别和节点相对顺序保持。
4. 本地故事 Inspector 的 Flow、Logic 输出复用端口编辑组件，可修改真实出口名称，内部源节点和项目画布同步。空名称不提交，ID、顺序及连线保持，使用全局 Undo/Redo 和保存机制。引用故事只读，导入副本可编辑。
5. 故事导航和分类资源列表共用输出端口的排序预览：隐藏原行、单个跟随预览、等高空位、120 ms 相邻让位，尊重系统动画设置，落点依据原始几何。展开故事组整体换位，资源仅在所属分类内排序。有效落下一次提交、一次 Undo；原位、Esc、失活和视图切换不提交；离开资源列表恢复预览，仍可拖入画布及属性框。沿用现有显示顺序字段。
6. 类型明确的引用入口先筛候选再生成文件夹、搜索和空状态：角色含个体／集体，物品含个体／组，会话和任务各自独立。本地其他故事和外部包采用相同筛选，排除已拥有／已引用内容；确认前再次检查类型、来源和当前可引用状态。通用入口保留全部类型。

游戏复验发现过一个真实漏点：选择存档恢复后没有此前台词／头像。已修复：每个活动会话仅保存一份最近已解析台词帧，恢复时用已有 LINE 帧静默发送，再发 CHOICE 帧；网络结构、Choice 文本、权威执行游标和历史身份保持，不重复播放声音或画面。旧存档可选缓存缺失仍可读取；旧提示缓存不展示。最终截图为 `six-fixes-game-context-restored-final.png`、`six-fixes-game-choice-completion.png`，早期失败保留。

拖动实测发现过展开组临时 DragLeave 会取消手势，已改为只恢复预览，落下／Esc／失活按实际状态决定提交。原始失败和诊断保留，生产源码不含临时诊断代码。

汇总断言见本地 `evidence/six-fixes-delivery-validation-receipt.json`。截图、TRX、日志、个人路径和 Data 指纹不上传 GitHub。
